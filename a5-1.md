# Activity 5 – Step 1: Without examples (zero-shot)

**Chatbot / model:** Gemini 3.1Pro

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
```

## Response

| Test ID | Scenario | Test Data Example | Expected Result |
| --- | --- | --- | --- |
| **TC-01** | Valid password at minimum length boundary (8 characters) with all requirements met | `Valid1xx` | Accepted |
| **TC-02** | Valid password at maximum length boundary (20 characters) with all requirements met | `ValidPasswordString1` | Accepted |
| **TC-03** | Invalid password just below the minimum length boundary (7 characters) | `Short1x` | Rejected |
| **TC-04** | Invalid password just above the maximum length boundary (21 characters) | `WayTooLongPassword123` | Rejected |
| **TC-05** | Invalid password within valid length but missing a mandatory digit | `NoDigitsHere` | Rejected |
| **TC-06** | Invalid password within valid length but missing a mandatory uppercase letter | `alllowercase1` | Rejected |
