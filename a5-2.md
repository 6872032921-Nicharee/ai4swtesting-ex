# Activity 5 – Step 2: With examples (few-shot)

**Chatbot / model:** Gemini 3.1Pro

## Prompt

```text
You are a software tester. Write 6 test ideas for the password rules delimited by three hashes. Use our team's test idea format.
###
A password must be 8 to 20 characters long and contain at least one digit and one uppercase letter.
###
For example:
* [BVA] 7 characters, one below the minimum ("Secret1") → rejected
* [EP] no digit ("SecretPass") → rejected
```

## Response

* [BVA] 8 characters, exact minimum length with digit and uppercase ("Secret12") → accepted
* [BVA] 20 characters, exact maximum length with digit and uppercase ("SuperSecretPassword1") → accepted
* [BVA] 21 characters, one above the maximum length ("SuperSecretPassword12") → rejected
* [EP] valid length, contains a digit but no uppercase letter ("secretpass1") → rejected
* [EP] valid length, contains an uppercase letter but no digit ("SecretPassword") → rejected
* [EP] valid length, contains only uppercase letters and digits ("SECRETPASS123") → accepted
